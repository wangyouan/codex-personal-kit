# CSMAR 数据库清单参考

以下内容来自 Workbuddy kit 的历史记录，只用于帮助规划数据需求，不代表当前订阅、入口地址或授权范围。

## 常见系列

- 公司研究：基本信息、财务报表、股东、股权质押、内部控制、会计信息质量、经营困境、供应链、审计、研发创新、诉讼仲裁等。
- 股票市场：交易、衍生指标、市场指数、融资融券、沪港通与深港通、停复牌等。
- 经济研究：宏观经济、国际宏观、工业行业统计、区域经济、专利、数字经济、碳中和等。
- 专题研究：事件研究、金融科技、股利政策、资本结构、投资者情绪、收益波动等。

## 选择原则

先按研究问题列出所需变量和时间范围，再确认机构当前可访问的子库与字段。不要依据历史入口名称或历史截止日期推断今天仍然可用。
