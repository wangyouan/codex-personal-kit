# CSMAR 页面与核验技术笔记

## 浏览器自动化

- CSMAR 通常是 SPA，数据区域可能嵌在 iframe 中；先检查当前页面结构，再决定使用 `frameLocator('iframe')` 或其他定位方式。
- 树形菜单通常需要区分父节点和可下载叶子节点。不要依赖固定标签页下标，按页面 URL、标题或可见内容确认目标页面。
- Vue/Element UI 页面有时不会响应单纯的 DOM click。只有在普通 Playwright 操作确实失败、且确认当前页面仍使用相同组件后，才考虑派发完整鼠标事件。
- 选择新子表后，字段全选和邮箱投递选项都应重新核验。弹窗遮挡时先关闭当前对话框，再继续操作。
- 批量任务应记录已提交的子表、错误和重试状态，避免重复提交和重复邮件。

## 邮件与下载

- 邮箱账号和授权码只保存在本机凭据或环境变量中，不写入仓库、日志或脚本。
- 下载链接通常是短期链接，应下载到按数据库系列组织的目录，并保留提交记录以便追溯。
- 下载后先验证压缩包和 Excel，再进入实证流程；不要把“提交成功”当成“字段完整”。
