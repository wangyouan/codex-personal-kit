# 前趋势差异：诊断与调整菜单

用于用户要求探索前趋势调整，或既有事件图显示值得解释的差异时。材料来源为用户提供的《平行趋势未通过的调整办法》（知行经管科研网，Koala，2026-11-17，17页）；它是方法导读，模拟结果与代码片段不是本机已验证的实现。以下为归纳规则，执行时核对原作者文档和本机版本。

## 先判断差异来源

保留原始基准与事件图。结合处理/对照原始均值、各年样本构成、模型调整后的年度系数及联合检验，区分持续斜率、临时冲击、构成变化、提前反应和估计器污染。原始均值仅作诊断，不代替调整后的识别。检验不拒绝可能来自低功效；单个显著点也不等于整条趋势不成立。维持用户要求的95%逐点区间；同时置信带或等效性检验仅在有明确问题时增加，标清与逐点区间的区别。等效界限要有经济尺度，不在看结果后选到刚好通过。

先写明怀疑来源、证据、对应调整及其改变的假设，再估计少量有理由的规格。看过结果后的新增选择标为adaptive，保留全部结果。不要将全部行业、窗口、匹配算法、趋势阶数交叉成无限网格。

## 可以进入 explore 的路线

| 怀疑来源 | 可考虑的调整 | 执行时必须保留的条件 |
|---|---|---|
| 错位处理造成TWFE事件系数污染 | 适配SA/CS/BJS | 按did-methods.md对齐目标；共同实施时不为凑列自动增加 |
| 有文件证据的提前反应或对照外溢 | 公告/生效时间设计、anticipation、干净对照池 | 时间变动来自制度事实；基期及对照资格同步调整，不因某年显著而改政策年或只删lead；排除规则可不看Y执行 |
| 基期规模、产业结构等同时影响处理选择与增长 | 条件DID：结果回归、IPW或DR；有机制依据的基期特征×年份项 | 使用未受政策影响的特征；普通TWFE加入时变控制不自动等同条件DID；区分结果水平与变化模型 |
| 处理与对照的基期特征分布不重叠 | 匹配DID、熵平衡或倾向得分加权 | 检查支持域、平衡、权重集中及目标人群变化；用对应估计器的推断 |
| 有解释的行业共同景气 | 行业×年份固定效应 | 核查行业内处理/对照支持和剩余识别；省级政策不能加入省×年后仍声称识别同一政策效应；行业分类时点需说明 |
| 稳定的政策前差异斜率 | 事前拟合后外推去趋势 | 沿用did-methods.md的两步联合推断与原始/调整图；短前史下拟合改善不等于独立验证 |
| 绝对增长与比例增长不同 | 有经济依据的水平/对数尺度 | 解释目标改变、零负值、单位；log(1+Y)不是精确百分比效应，不能按前趋势p值选变换 |

条件DID需声明基期特征的参考年或政策前汇总窗口，不把滚动L.X自动视为政策前变量。共同处理也可为条件平行趋势使用适配的CS/DR实现，这与自动做SA/CS/BJS比较是不同目的。DRDID基本接口是两期两组；多期动态用适配实现并核对联合协方差、基期、权重及样本，不能把互不相关的两期标准误拼成事件图的联合检验。省级政策仍按省级依赖结构推断，不能照抄示例的cluster(id)。

## 匹配、权重与前史验证

每个单位先构造一行处理前特征，再合并权重回面板；不默认逐年重新匹配而让对照构成随年变动。登记算法、变量、距离/矩约束、阈值及训练年份。ATT倾向权重的对照部分与p/(1-p)成比例；报告分布、极端权重、处理/对照支持和ESS=(sum w)^2/sum(w^2)。ESS不是独立省份数，不能替代聚类数。剔除不重叠的处理单位改变目标ATT，需报告损失与人群。

使用政策前结果训练匹配、权重或趋势时，若前史足够且本阶段安排了预测验证，可用较早年份拟合、较晚的未处理年份验证，固定后再估计政策后效应。只用2014—2016等短前史时不强制切分：说明验证不足，按既定计划延长前史。用来训练的年份变得平坦属于拟合表现，不能称为独立验证。避免只匹配一个含噪声的结果年份导致均值回归。

推断计入所采用估计程序所需的第一步不确定性。不能把估计权重一律当已知；固定邻居数最近邻匹配不能机械套用普通bootstrap。选择有对应推断依据的实现，沿用政策分配层级，并记录重抽样是否重做构造及估计。

## 条件性扩展：不自动升级设计

以下纳入方法菜单，但仅在项目范围已包含该路线、经济假设与数据支持明确时执行。否则记录所需条件与未运行原因，不把它们变成所有Y的必要检查；既有授权无需重复询问。

- 合成控制/SDID：需要合格供体、足够前史及实现支持的面板；登记权重、拟合/验证窗口和目标。权重选择不得用处理组政策后结果拟合反事实；SDID的时间权重规则按正式算法执行，不能误禁其使用未处理对照的后期信息。展示轨迹、差距和权重。推断与处理单位数和分配层级一致，少数处理省份不能当大量独立企业处理。
- 交互固定效应、广义合成控制、矩阵补全：要求可学习的稳定共同因子/低秩结构与足够历史；只用未处理信息训练，按时间结构验证复杂度。不能靠更平滑的图宣称解决新的处理组特有冲击。
- DDD：需额外未受政策及外溢影响的辅助群体、可解释的偏误抵消条件和必要低阶交互；是新增识别假设，不是普通DID自动升级。
- 代理结果/IV事件研究：先证明代理反映混淆且不受政策影响，按原文核实排除条件与方程；不机械把政策lead全部当工具。
- HonestDiD按既定阶段执行；用户暂缓继续有效。它描述允许偏离后的结论范围，不负责让原始前趋势变得不显著。

## 记录与交付

扩展spec_registry的reason/模型设置，保存suspected_source、evidence、adjustment_route、training_years、validation_years、covariate_reference、weight_method、support_rule、target_change、inference和adaptive。无训练/权重时相关项记不适用。原始与调整后的系数、量级、区间、事前检验、动态路径、样本及依赖假设并列；同一规格静态与事件模型保持同样本，不强求不同设计人群完全相同而掩盖实际差异。未经运行不得标为方法已验证；模拟示例数字不得进入项目结果表。
