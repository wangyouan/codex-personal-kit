# DID 基准与必要检查

范围仅为基准结果、处理前事件研究与联合检验、约定阶段内适用的一套 HonestDiD，以及设计或用户要求的 SA/CS/BJS 比较。用户要求先做小实践、暂缓 HonestDiD 时，先完成当阶段基准与趋势检查，保留敏感性输入并登记 deferred_by_user。不要默认加机制、异质性、安慰剂、Bacon 分解或其他估计器。

## 先固定比较对象

从项目代码和字典记录 `outcome`、单位/时间、真实首次处理期、处理反转与提前反应、对照组资格、估计窗口、目标 ATT/动态效应、聚合权重及聚类依据。单位—时间键必须唯一。缺少处理含义时不能根据结果猜测。

已有基准先复现；没有基准时按设计选择主估计。共同实施且条件适用时可用线性 FE DID。错位实施时，不把普通 TWFE 的显著系数自动解释为目标 ATT；没有必要仅为凑一列而新增 TWFE。反复处理、连续强度等设计不可强套不可逆首次处理框架。

按设计和用户范围确定执行清单。共同实施、存在合格 never-treated 对照且普通 FE DID 适用时，基准、同口径事件研究及适用的 HonestDiD 可以构成完整必要检查；无需为凑列强制运行 SA、CS、BJS。用户要求比较时仍执行；用户已明确免除时不反复补回。错位实施则保留适配的 SA/CS/BJS 比较。共同实施不等于这些方法在统计上不适用：未要求的可选比较记 `not_requested`，真正设计不适配才记 `not_applicable`。其余状态沿用 `search-contract.md`，并保存原因。环境缺包不是统计上的不适用，报错也不等于效应为零。不得因一个方法不显著就省略已要求的比较，也不要求三个方法全部显著。

比较前核对实际样本、支持队列、对照组、horizon 和权重。相同原始样本不保证相同估计对象；无法对齐时明确列出差异。对不同总体或目标参数分别分配标识，不直接用系数差异判断哪个估计器更好。

## 复用已安装的估计后端

从本文件所在技能目录向上定位共同的 `skills/` 根目录，再读取相邻技能；不要硬编码用户目录：

- `r-econometrics/SKILL.md` 与其 `references/did-event-study.md`：R 方法与运行环境。
- `stata-regression-workflow/SKILL.md`、`stata-runner/SKILL.md`：Stata 项目和日志检查。
- 项目已有 Python 实现时读取 `pyfixest/SKILL.md`，核实已安装版本的实际方法支持；不要将一个 DID 估计器冒充另一个。

沿用项目主要语言，可为一个必要方法使用另一已验证后端。优先核实本地帮助、函数参数和包版本；网络文档用于补充，不能假定本机已具备最新 API。未实际运行的模板只标记为待执行。

## SA、CS、BJS

| 方法 | 可用实现入口 | 关键检查 |
|---|---|---|
| SA：Sun–Abraham | R `fixest::sunab`；Stata `eventstudyinteract` 按本地帮助使用 | 队列、参考组、基期和事件时间聚合；始终已处理者单独处理 |
| CS：Callaway–Sant'Anna | R `did::att_gt` 后 `did::aggte`；Stata `csdid` 按本地帮助使用 | 对照组、协变量时点、平衡面板处理、group-time 支持和聚合权重 |
| BJS：Borusyak–Jaravel–Spiess | 作者 Stata `did_imputation`；R `didimputation::did_imputation` 的 BJS 实现 | 未处理样本拟合、可插补范围、目标权重、各 horizon 有效 treated 数 |

**SA。** `sunab(cohort, period)` 的 cohort 是单位不变的首次处理期。日历时间模式下，落在观测期之外的过去队列可能被误当 never-treated；先识别始终已处理者。never-treated 的编码不能直接照搬 CS 的 0。保存 cohort × event-time 估计及聚合规则，不能拿未聚合协方差配聚合后系数。[fixest 官方文档](https://lrberge.github.io/fixest/reference/sunab.html)

**CS。** `gname` 中 never-treated 用 0；控制组按设计选择 `nevertreated` 或 `notyettreated`。明确 `est_method`（`reg`、`ipw`、`dr`）及其依据，不把 CS 称为一次普通 OLS。显式记录 `allow_unbalanced_panel`：默认可能删除未完整观测的单位，且时变协变量的处理也与面板设定有关。聚类和 bootstrap 设置依据本机版本核实；保留 group-time 与动态聚合对象。[did 官方文档](https://bcallaway11.github.io/did/reference/att_gt.html)

**BJS。** 作者命令的位置参数为 `Y i t Ei`，其中 `Ei` 缺失表示 never-treated。只用未处理观测拟合反事实；无法插补的 treated 必须登记，不能静默通过 `autosample` 改目标总体。按真实 horizon 设定窗口和权重。`pretrends(k)` 是单独的处理前诊断，加入它不改变处理后效应；其参考结构不能按普通 TWFE 的单一遗漏期解释。保存 `e(b)`、`e(V)`、每个效应的支持及作者提供的处理前联合检验；被缺少有效样本压成零的输出须标记为不支持，不能当作真实零效应。[作者帮助文件](https://raw.githubusercontent.com/borusyak/did_imputation/main/did_imputation.sthlp)

R 后端可使用 Kyle Butts 维护的 [didimputation](https://cran.r-project.org/package=didimputation)，核实当前版本的 `yname/gname/tname/idname`、`horizon`、`pretrends` 和 `cluster_var` 参数及 never-treated 编码；不可照搬 Stata 位置参数和缺失规则。表格输出的边际 SE 不能冒充完整联合协方差；没有有效矩阵/联合检验接口时明确记载，而非自行拼对角矩阵。

## 平行趋势的最小输出

输出适用的事件研究图、处理前系数联合检验、基期、窗口、各 horizon 支持和聚类口径。点置信区间和同时置信带要明确区分。共同实施的普通 FE 事件研究使用其完整聚类协方差；BJS 使用其处理前检验接口；SA/CS 使用与其定义和协方差一致的联合检验。只有一个非归一化 lead 时如实标为单项事前检验；没有该 lead 时不能报告事前联合检验。窗口筛选还须满足 [search-contract.md](search-contract.md) 的实际年份与样本支持要求。

联合检验不拒绝不是平行趋势成立的证明；不要求每个 lead 都不显著。不能根据处理前 p 值反复缩短窗口、换样本或删除队列。必要时期没有支持时标记限制，不能把省略系数填零。

## 事前去趋势与条件性候选

只有用户要求或已登记的方法才运行；不因看到一张不平行的图自动尝试多种去趋势直到通过。优先复用项目已调通并核对过的方法，记录第一步的年份、样本、组别、权重、基期和趋势函数。只用政策前数据估计趋势，再外推；不能用处理后结果拟合所谓“事前趋势”。

原始与去趋势的静态结果和年度图并列，使用同一批企业年、滞后控制、固定效应和聚类。第二步推断需计入第一步趋势估计误差及两步协方差，可使用经过验证的联合聚类影响函数，或每次都重做两步的适配bootstrap。不能把估计趋势当成已知常数。对剩余事前对比按有效协方差秩检验；机械归零或秩不足不等于通过平行趋势。

在线性趋势差模型中，若政策前处理组相对对照组的斜率为 s、基期为 t0，则年度事件系数的调整是 `b_adjusted(t) = b_raw(t) - s*(t-t0)`（以具体模型的投影核对）。静态系数使用设计矩阵对应的趋势投影，不能直接套“平均年份×s”。至少报告s、代表年份的原始系数/趋势调整项/调整后系数，解释较远年份是否主要由外推形成。只有几个事前年份时，漂亮的平滑上升图不能独立证明反事实趋势可靠。

把原始无明显平均效果、去趋势后有信号的Y单列为**依赖趋势调整的候选**。它仍值得考察，但经济解释是“相对于延续原趋势的反事实”，不是原始结果同幅度增加。结合量级、方向、持续性和剩余事前走势判断，不仅看事前p值。较短主窗口可减少长期外推，较长前史可检查斜率稳定性；两者依据用户计划登记，不能为提高p值反复删年份。

用户暂缓HonestDiD时，不因此排除该候选；保留不确定性说明和待检状态。如果已有敏感性结果，应准确说明哪些限制范围下区间排除零、何处包含零，不能概括为“全不稳健”，也不能把很强限制下的结果当成无条件结论。DeltaSD的M=0允许非零但严格线性的差异趋势，并不等于原始平行趋势。

## HonestDiD：只做一套已适配分析

在看敏感性结果前，确定一个适配的动态估计、目标效应、一个有解释的限制族和有限参数网格。共同实施时可直接使用普通 FE DID 事件研究；错位实施优先使用适配的 SA/CS 系列，不能把普通 TWFE 的异质处理污染忽略掉。来源模型应如实命名，普通 DID 不冒充 SA。是否在本阶段运行先服从用户安排，再检查数据、方法与环境条件；不由处理前 p 值决定。暂缓时保存原始年度系数、完整联合协方差、实际样本和目标时期，不提前把暂缓写成已经检验或不通过。输出允许平行趋势偏离后的区间及结论改变范围，不给“通过/不通过”评级。

准备输入时必须：

1. 对齐按事件时间排序的 `betahat` 与完整联合 `sigma`，移除控制项及归一化零系数的对应行列；不能仅用 SE 拼成对角矩阵。
2. 核实连续时期、基期、提前反应和端点合并是否满足适配条件。CS 作者示例要求统一基期；SA 聚合时同时变换系数和协方差。
3. 用 `l_vec` 明确目标时期或处理后平均。默认第一期 post 的结果不能代表整个 ATT。逐年系数的等权平均、按观测数加权平均和静态 `treat × post` 系数是不同目标；改变观察终点也可能改变目标，不能混成同一个“政策后平均效应”。
4. 保持与主分析相同的依赖结构。用 influence functions 构造矩阵时需正确处理聚类；不能直接复制独立单位示例代替省级等更高层聚类。对角线与对应模型 SE 核对，但该核对本身不能证明非对角元素正确。
5. 不将 BJS 的 `pre_h` 和 `tau_h` 机械拼接接入；初版不开发未经验证的 BJS 偏差映射。缺少有效矩阵、前期支持或适配时，保留原结果并标明 HonestDiD 尚未完成。
6. 检查所装版本的数值反演网格及接受区间是否碰端点。零中心默认网格可能未覆盖远离零的效应；空接受集出现时先核对搜索范围和分辨率，记录修正前后设置/警告，不改变数据或经济约束来追求显著。网格修正不能替代对真正空集、无界或数值失败结果的如实报告。
7. 逐窗口核实限制族所需的事前信息。相对幅度限制 `bound="deviation from parallel trends"` 可以使用一个非归一化事前系数，但此时仅由一次事前变化提供标尺，应标明信息有限；不要把这一条件推广到其他限制族。相同 Mbar 在不同窗口可能对应不同标尺。记录 HonestDiD 的渐近区间与基准有限聚类 t 区间的差别。

R 官方入口包括 `constructOriginalCS`、`createSensitivityResults_relativeMagnitudes` 和 `createSensitivityResults`；按本机帮助选择参数。作者文档有 SA 与 CS 的适配示例，试用时核实版本与聚类条件后使用。[HonestDiD 作者文档](https://github.com/asheshrambachan/HonestDiD)、[限制族与参数手册](https://asheshrambachan.r-universe.dev/HonestDiD/doc/manual.html)。

## 交付与完成状态

最小交付：基准表、已要求的估计器对照表、事件图与处理前联合检验、适用时的 HonestDiD 表图，以及完整方法设置和失败记录。共同实施且未要求 SA/CS/BJS 时，不把缺少这些可选比较记为未完成必要检查。采用匹配时保存其必要平衡/支持结果。所有表图能追溯到 `spec_id`、outcome/model ID、实际估计样本、目标效应、模型对象和代码。

本阶段要求的必要方法未运行或诊断未完成时，说明具体缺项，不将本阶段规格标成已完成；用户明确留到后续的检查单列 deferred_by_user，可完成并交付当前小实践，但不声称后续稳健性已完成。显著、不显著和反向结果均保留；这些诊断不自动消除规格搜索带来的选择问题。
