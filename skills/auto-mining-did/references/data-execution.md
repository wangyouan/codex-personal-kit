# 多指标实践：来源与执行

用于用户给定一份Y清单、需从本机数据库构造变量并分批估计的任务。不要把清单替换成最容易取得的两项，也不要把下面的数据来源例子变成所有项目的默认口径。

## 从完整名单推进

- 先建立逐项公式、来源、单位、控制、适用人群与状态登记，按依赖关系分批构造—回归—画图。候选是否入选与原始数据能否正确构造分开处理。每项保留完成、覆盖受限、来源受限、失败待修复或明确暂缓的状态。
- 如果预算不足以覆盖名单，先调整并说明预算或登记分阶段安排；不要在少数结果完成后把整个任务交付为已完成。预算耗尽则如实停止新估计，列明剩余项。
- 在核实字段名、压缩包内部成员、日期范围和已有复用脚本前，不把空提取结果视为“缺数据”。修正字段/日期/单位错误后重建受影响项，错误版本归档为纠错记录，不作为合法备选口径。

## 本地数据库核查

- 表名或“全时段”文件名不证明实际覆盖。核实每年处理/对照组、企业数和共同有效交易日；查找历史分卷或另一可信来源后再判定缺口。按文件实际格式读取，不只按.zip/.7z后缀判断；CRC损坏不绕过验证使用。
- 阅读表内标题、单位行和字典；不同表的日期列可能为Year、Date、EndDate或公告日期。区分会计年度、实际发生日和公告日。更正标志不是自动可删除的报表版本：例如CSMAR的IfCorrect表示是否发生差错更正，应按具体Y的测量/信息可得性要求处理。
- 原始金额的元/万元/亿元、比例/百分数、股票市值的元/千元分别核实。因子模型的无风险利率要匹配定义和生效日；不能把两个口径不同的市场指数之差误当作无风险利率。
- 跨库补时间缺口先核对股票身份、复权/含息规则、重叠日期数值与舍入精度。不降低原定有效日门槛来掩盖缺失。只在同口径核实范围内补充，并保留来源标签和覆盖变化。
- 事件表的无记录不自动等于无事件；需确认来源覆盖与零值含义。不能把只在正向披露样本中可算的金额强度说成全体企业的发生概率。用事件/授予轮次等真实身份去重，日期修订不能自动生成第二笔事件；累计比例不能逐笔相加。
- 缺专利公开日不能用申请日冒充公开后三年被引窗口；缺真实中间投入不能用收入/员工冒充TFP。明确缺哪个定义条件，并保留已核实的部分材料。

## 样本、计算与缓存

- 按用户指定控制口径执行。需要L.X时，按同一企业恰好t−1匹配，在截取主窗口之前构造；缺年份不取“上一行”。因变量与控制有机械重合时，在看该Y结果前记录调整理由；滞后本身不保证控制不受政策影响。
- 每个Y静态与事件模型使用同一实际样本、控制、固定效应和聚类。缺某期不自动放弃所有可识别结果：注明静态/动态各自支持、有效事前检验维数及不能完成的检查，不补归一化之外的零系数。报告覆盖受限结果时明确实际窗口和人群。
- 对构造任务和依赖回归设置完成标志：写完临时数据、校验后再原子发布，并等待构造进程完成。不能让回归读取正在写入、尚缺最后一个Y的中间面板，然后把它缓存为来源缺失。
- 缓存键包含Y定义、数据内容、样本、控制/FE、窗口、目标、推断与代码版本；不能只按Y名称复用。纠正来源或构造后只失效受影响的模型及下游图表/检查。不要把明确尚未完成的构造缓存成永久缺项。
- 使用追加式执行台账记录每次估计、失败/数值重试、缓存复用和耗时，不用新一批覆盖旧日志。分别统计唯一口径、实际调用和内部bootstrap重复；后台进程须有完成状态和错误记录。
- 把明确暂缓的检查留在清单；交付完整总表、实际样本与协方差、所有所需图、经济量级及逐项原因。仅重点图可精选，全部Y行不能因不显著而消失。复核代表性模型及关键输入恒等式，避免新增与任务无关的检验套件。
