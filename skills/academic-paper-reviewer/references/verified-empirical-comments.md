# Verified empirical comments

For economics, finance, and archival accounting reviews, attach a source location and observable evidence to each major concern. Classify whether it is a verified error, interpretation dispute, missing exhibit, or optional improvement. Mark unavailable evidence as unverified; do not invent page numbers, results, or tests.

The kit's maintained field-specific protocol is [Verified referee comments](../../econ-fin-writing/references/verified-referee-comments.md). Read it when `econ-fin-writing` is installed. The present file provides a standalone fallback when that companion skill is unavailable.

Record `severity, topic, location, evidence, issue, consequence, action, verification_status` for major comments. Keep editing notes separate. Tie additional-analysis suggestions to a specific threat. Review the research question the author actually poses: descriptive, theoretical, structural, and causal papers require different evidence.

Check cross-table sample changes, variable units/construction, event timing, control/FE definitions, clustering, treatment-effect interpretation, economic magnitude, and construct validity where relevant. For re-review, match each original concern to the revised exhibit and verify resolution. Advisory reviewer opinions are not journal acceptance forecasts.

Source inspiration: [Barrios econ-referee](https://github.com/Barrios88/barrios-skills/tree/d50afc62f4c67535a1949d029dfa0462feb906fd/skills/writing-and-review/econ-referee). Existing review modes and independent perspectives remain applicable.
