# TradeWar Project Conventions

Use this reference only when the current workspace is the TradeWar project.

## Local Path Policy

Keep machine-specific project roots, output folders, editor URLs, and historical archive paths in `~/.codex/memories/local/` or the local project README. Do not add absolute paths, account-specific cloud links, or local notebook identifiers to this repository.

Before editing, identify the active presentation source from the workspace itself and verify the intended output directory. Treat historical material as read-only unless the user asks to modify it.

## Slide Work

- Confirm the target conference and source `.tex` file before changing content.
- Preserve citation keys, labels, data sources, and established visual conventions.
- Render and inspect the PDF after substantive changes.
- Keep generated auxiliary files outside the tracked source tree.
