# Supported Table Types

## Regression

Show model numbers, dependent variables, coefficient/statistic pairs, and model metadata. Include controls, fixed effects, clustering, observations, and fit statistics when supplied. Put the focal variable first, controls next, and model metadata last.

## Descriptive statistics

Use columns such as N, Mean, Std. Dev., Min, percentiles, Median, and Max. Group variables by role only when the grouping is substantively useful. Do not add significance stars.

## Correlation matrix

Show one triangle unless the journal requests a full matrix. Put variable numbers and names in a key or row labels. State Pearson/Spearman and whether stars or p-values are shown. Keep the diagonal convention consistent.

## Variable definitions

Use columns for variable name/symbol, definition, construction, and source as needed. Allow multipage layout, wrap prose at word boundaries, and repeat headers. Never invent a source or construction rule.

## Difference, balance, and density tests

Use grouped headers for samples/treatments. Report group N, mean or share, difference, and p-value or test statistic. Identify the test and standard-error assumptions in the note. Do not put p-values in parentheses unless the template does so.

## Robustness, heterogeneity, and subsamples

Use panels or grouped column headers to make the comparison dimension explicit. Keep common controls and metadata aligned across models. A blank cell means not estimated/not applicable only when the note defines it; otherwise use an em dash or an explicit label required by the journal.
